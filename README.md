# CI/CD Task Management Application

## Project Name
ci-cd-final-project
## Project Description
This project demonstrates the implementation of a Continuous Integration and Continuous Deployment (CI/CD) pipeline using GitHub Actions and Red Hat OpenShift Pipelines (Tekton).

The application is developed using Python Flask and provides basic task management functionality.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- GitHub
- GitHub Actions
- Tekton
- Red Hat OpenShift
- Docker

## Project Features
- Add tasks
- View tasks
- Update task status
- Delete tasks
- Automated code linting
- Automated unit testing
- Automated application deployment

## CI/CD Workflow
1. Push application code to GitHub.
2. GitHub Actions executes Flake8 linting.
3. GitHub Actions runs unit tests using Nose.
4. Tekton manages pipeline tasks.
5. OpenShift deploys the application.
